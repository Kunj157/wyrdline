# Gemini CLI

Merge `settings.json` into `.gemini/settings.json` (project) or your
user settings to report Gemini CLI's tool calls, prompts, and final
messages to Wyrdline. Outside a `wyrd run` session `wyrd hook` is a
silent no-op.

Status: built from Gemini CLI's documented hook contract; not yet
verified in a live run. See [docs/architecture/adapters.md](../../docs/architecture/adapters.md).
